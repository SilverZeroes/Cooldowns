# Cooldown CLI

A simple command-line cooldown manager written in Python.

## Features

- Persistent cooldown timers
- Create timers
- Reset timers
- Remove timers
- JSON storage

## Usage

```bash
python main.py
```

## Add timer

```bash
python main.py add
```

## Remove timer

```bash
python main.py remove
```

## Reset cooldown

```bash
python main.py reset
```
